# Ridiculous at First Glance, Real by the Second

One sentence (187 characters) pitching a bizarre startup idea that sounds absurd until you realise it would actually sell: selling naming rights to potholes — cities auction each crater to local businesses, whose logo gets stencilled around it until the road is fixed, so the worse the road, the higher the bid.

## Run

```sh
python3 main.py
```

`main.py` writes the one-sentence pitch to `/output/entry.txt` (1–200 characters, UTF-8). The entry is deterministic: the same sentence is produced on every run.
